# IT112: Computer Programming I (Python)

## Weekly Task: Airtel USSD Menu Simulation

### 📌 Project Description
Design and implement a software program to **simulate the Airtel USSD menu** accessed through the Unstructured Supplementary Service Data (USSD) code **`*117#`**.  

The application should:  
- Present the available menu options.  
- Allow the user to input a selection.  
- Navigate through menus to access the associated functionalities.  

⚠️ **Note:**  
This project is a **simulation only**. No real financial transactions are made. The payment process must be implemented as text-based prompts, since no external APIs will be integrated.

---

### 🎯 Learning Objectives
By completing this task, students will be able to:

1. Demonstrate an understanding of **USSD technology** and its role in mobile communication systems.  
2. Apply programming skills to design and implement a **text-based interactive system**.  
3. Analyze and replicate an **existing real-world menu structure** in a simulated environment.  
4. Implement **user input handling** and **menu-driven navigation** in software.  
5. Appreciate the distinction between **simulation** and actual system integration (e.g., payments via APIs).  
6. Strengthen **problem-solving abilities** by designing a solution that models a real telecom service.
